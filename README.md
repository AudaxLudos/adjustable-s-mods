> ### With the 0.98.5a patch for Starsector, that adds features to remove specific s-mods. This mod will now be archived and will not be updated in the future. You can still fork and modify the mod for your own purposes.

# Adjustable S-Mods
A mod for Starsector that allows the player to remove s-mods or to increase the max s-mod limit of a ship.
